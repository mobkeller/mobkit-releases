# MOB Kit

MOB Kit es un plugin VST3 para Windows (FL Studio y otros DAW) de MobKeller DSP: captura de audio, analisis a MIDI, Router entre instancias y grabador de video.

## Descargar

Ve a **[Releases](../../releases/latest)** y descarga el `MOB-Kit-Setup-X.Y.Z.exe` de la ultima version.

## Instalar

1. Cierra FL Studio.
2. Ejecuta el instalador (pide permisos de administrador).
3. Abre FL Studio y busca MOB Kit en tus plugins (si no aparece: *Options > Manage plugins > Find installed plugins*).

El instalador reemplaza la version anterior. Tus videos, sonidos y ajustes no se tocan.

## Actualizaciones

MOB Kit avisa dentro del plugin cuando hay una version nueva. Pulsa **Descargar**, cierra FL Studio e instala el nuevo `.exe`.

## Desinstalar

*Configuracion de Windows > Aplicaciones > MOB Kit > Desinstalar.*
